# OZI
---
## Опис проєкту

Цей проєкт реалізує підписування зображень цифровим підписом за допомогою алгоритму RSA та приховування підпису в зображенні за допомогою методу найменш значущого біта (LSB). 

Метою є гарантія автентичності та цілісності зображення, з можливістю перевірити його підпис, не змінюючи візуальний вигляд зображення.

---

## Принцип роботи

1. Генерується пара RSA-ключів (приватний та публічний).
2. За допомогою приватного ключа створюється цифровий підпис оригінального зображення.
3. Підпис вбудовується у зображення методом LSB без помітної зміни його вигляду.
4. Для перевірки справжності підпису використовується публічний ключ та порівнюється оригінальне зображення з витягнутим підписом.

---

## Генерація ключів RSA

Генерація ключів відбувається за допомогою модуля `cryptography`. Створюється приватний ключ довжиною 4096 біт, з якого також отримується відповідний публічний ключ.

Ключі зберігаються в папці `keys/` у форматах PEM:
- `private.pem` — приватний ключ (PKCS8)
- `public.pem` — публічний ключ (SubjectPublicKeyInfo)


## Підписування 

1. Генерація підпису
- Оригінальне зображення зчитується у байтовому вигляді.
- За допомогою RSA-приватного ключа на ці байти створюється цифровий підпис з використанням:
   - алгоритму хешування SHA-256,
   - схеми підпису PKCS1v15.

Отриманий підпис має фіксовану довжину (512 байт при 4096-бітному ключі).

2. Перетворення підпису в бітовий потік
- Кожен байт підпису перетворюється в 8-бітову послідовність (0 або 1).
- У кінець додається спеціальний маркер SIGNATURE:, закодований у двійкову форму. Це необхідно для подальшого коректного виділення підпису з зображення.

3. Вбудовування підпису в зображення (LSB-стеганографія)
- Зображення відкривається як масив пікселів у форматі RGB (три канали на кожен піксель).
- Кожен біт з цифрового підпису послідовно записується в найменш значущий біт одного з каналів (R, G або B).
- Заміна виконується побітово:

   - Наприклад, якщо значення синього каналу пікселя = 10011011, а наступний біт підпису = 0, то змінене значення буде 10011010.
   - Таким чином, один біт підпису вбудовується в кожен канал одного пікселя, не змінюючи візуально помітно саме зображення.

Для підпису довжиною 512 байт + маркер потрібно приблизно 4100 біт → ~1366 пікселів (при використанні всіх трьох каналів RGB).

4. Збереження результату
Змінене зображення з вбудованим підписом зберігається у новий файл у папці output_image/.

## Перевірка підпису 

1. Витяг підпису

- Зображення з підписом зчитується та перетворюється у масив пікселів.
- Із кожного пікселя зчитується найменш значущий біт (LSB) трьох кольорових каналів (R, G, B).
- Отримані біти об’єднуються у байти до виявлення маркера SIGNATURE:, який позначає завершення підпису.
- Послідовність байтів до маркера вважається витягнутим підписом.

2. Зчитування оригінального зображення

- Оригінальне (непідписане) зображення відкривається та зчитується у байтовому вигляді.
  
3. Верифікація підпису

- Імпортується RSA-публічний ключ із файлу.
- Витягнутий підпис перевіряється на відповідність байтам оригінального зображення за допомогою:
   - алгоритму хешування SHA-256
   - схеми перевірки підпису PKCS1v15

- У випадку успішної перевірки — повідомляється, що підпис вірний. Інакше — підпис вважається недійсним.
  
## Структура проєкту

```plaintext
project/
├── input_image/
│   └── test_image.png           # Оригінальне зображення
├── output_image/
│   └── signed_image_lsb.png     # Зображення з вбудованим підписом
├── keys/
│   ├── private.pem              # Приватний ключ RSA
│   └── public.pem               # Публічний ключ RSA
├── create_keys.py               # Генерація ключів
├── sign_image.py                # Підписування зображення
├── check_image.py               # Перевірка підпису
├── lsb_utils.py                 # Реалізація LSB-стеганографії
└── README.md                    # Опис проекту
```

## Інструкція з використання

### Встановіть необхідні бібліотеки
<pre lang="markdown">pip install -r requirements.txt</pre>

### Кроки запуску
1. Згенерувати ключі:
<pre lang="markdown">python create_keys.py</pre>
2. Підписати зображення:
<pre lang="markdown">python sign_image.py</pre>
3. Перевірити підпис:
<pre lang="markdown">python check_image.py</pre>

## Інноваційність рішення
- Підпис приховується візуально непомітно за допомогою LSB-методу, що не впливає на зовнішній вигляд зображення.
- Використання RSA гарантує автентичність і неможливість підробки.
- Підтримка форматів зображень PNG, BMP, JPEG.
- Використання маркера SIGNATURE: дозволяє точно ідентифікувати межі підпису.
